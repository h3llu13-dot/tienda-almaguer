# Tienda Almaguer: Inventario y Punto de Venta

Aplicación instalable (Chromebook, PC, Android) que funciona sin internet.

**Abrir e instalar:** https://h3llu13-dot.github.io/tienda-almaguer/

Abra la dirección en Chrome o Edge y pulse el ícono de **instalar** en la barra de direcciones.

Los datos de la tienda **no** se guardan aquí. Quedan en cada equipo, y aquí solo está la aplicación.
